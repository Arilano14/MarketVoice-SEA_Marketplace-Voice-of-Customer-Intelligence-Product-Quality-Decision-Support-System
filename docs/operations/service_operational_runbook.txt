1. STARTING THE FASTAPI MICROSERVICE
# Launch via runner script:
python scripts/runners/start_api.py

# Or directly via uvicorn:
python -m uvicorn marketvoice.api.application:app --host 127.0.0.1 --port 8000

2. PROBE VALIDATION
- Liveness: curl http://127.0.0.1:8000/health
- Readiness: curl http://127.0.0.1:8000/ready

3. N8N WORKFLOW EXECUTION
- Dashboard URL: http://localhost:5678
- Workflow File: workflows/n8n/workflows/marketvoice_review_triage.json
