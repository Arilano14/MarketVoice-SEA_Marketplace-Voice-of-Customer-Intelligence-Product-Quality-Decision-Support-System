LOGS — runtime output artefacts (LOCAL_ONLY)

This directory captures runtime logs generated by MarketVoice SEA Python scripts, validators, and execution wrappers. The directory is tracked via the .gitkeep placeholder; log files (*.log, *.jsonl, timing traces, validator raw output) are LOCAL_ONLY and excluded from version control per .gitignore.

REGENERATE AFTER CLONE:
  mkdir logs     # on Windows: New-Item -ItemType Directory -Force logs

POLICY:
  - All files ending in .log or produced by Python logging.FileHandler
    are written here only; never commit them.
  - Retain locally for debugging; delete with impunity between runs.
  - For long-running validators, redirect stderr/stdout to a timestamped
    file under logs/ if you need an offline audit trail.
